pip # Icequake Visualization — Prototype v1

3D browser visualization of seismic event evolution in space and time.  
Dataset: Rhône Glacier, Switzerland · July – August 2020.


## Project structure

```
icequake-viz/
│
├── data/
│   ├── raw/                        <- put your original CSV files here
│   │   ├── detections_jittered.csv   seismic events (required)
│   │   ├── meteo.csv                 meteorological data
│   │   ├── runoff.csv                water runoff
│   │   └── stations.csv              sensor positions
│   │
│   └── processed/                  <- (reserved for future intermediate files)
│
├── scripts/
│   └── convert_data.py             <- run this to regenerate public/data.js
│
└── public/                         <- open index.html in your browser
    ├── index.html
    ├── style.css
    ├── app.js
    └── data.js                     <- auto-generated by script, do not edit by hand
```


## Quick start

### 1. Install Python dependencies

```bash
pip install pandas
```

### 2. Run the conversion script

```bash
# Convert full dataset (37 000+ events)
python scripts/convert_data.py

# Or use a sample for faster development
python scripts/convert_data.py --sample 5000
```

This reads all CSVs from `data/raw/` and writes `public/data.js`.

### 3. Open in browser

```
public/index.html   ← just double-click it, no server needed
```



## How the conversion works

```
data/raw/*.csv
      │
      │  scripts/convert_data.py
      │  - reads each CSV with pandas
      │  - renames columns to unified names (t, x, y, z, q)
      │  - parses timestamps → Unix seconds
      │  - resamples meteo/runoff to hourly (reduces size)
      │  - computes metadata (t_min, t_max, z_range, ...)
      │  - serialises everything as compact JSON
      ▼
public/data.js
      │
      │  loaded by index.html as a plain <script> tag
      │  exposes: EV, METEO, RUNOFF, STATIONS, META
      ▼
app.js  reads these arrays and renders with Three.js
```

## Adding a new dataset

1. Put your CSV in `data/raw/`
2. Make sure it has columns that map to the unified schema:

   | Unified | Accepted column names |
   |---|---|
   | `time` | time, timestamp, datetime, date |
   | `x` | east_shift, easting, x, lon, longitude |
   | `y` | north_shift, northing, y, lat, latitude |
   | `z` | depth_ellipsoid, depth, elevation, z |
   | `q` | semblance, quality, magnitude, snr, q |

3. Add a new converter function in `scripts/convert_data.py`  
   (copy the pattern of `convert_events()`)
4. Call it in `main()` and add it to `write_data_js()`
5. Re-run the script

## Unified event format

Each event in `EV`:

```json
{ "t": 1593683515.4, "x": -8.0, "y": 259.2, "z": -2537.2, "q": 0.137 }
```

| Field | Meaning | Unit |
|---|---|---|
| `t` | Unix timestamp | seconds |
| `x` | East shift from reference point | metres |
| `y` | North shift from reference point | metres |
| `z` | Depth (negative = below surface) | metres |
| `q` | Quality / semblance score | 0 – 1 |
